אתגר הכימיה – התקנה באנדרואיד

1. חלץ את קובץ ה-ZIP.
2. העלה את התיקייה לאחסון אתר סטטי מאובטח (HTTPS), למשל GitHub Pages.
3. פתח את כתובת האתר ב-Chrome באנדרואיד.
4. לחץ על "התקן אפליקציה" אם מופיע, או בתפריט ⋮ בחר "הוספה למסך הבית" / "התקנת אפליקציה".

הערה: זו אפליקציית PWA ולא APK. אחרי טעינה ראשונה באתר היא שומרת את קובצי האפליקציה לשימוש אופליין.
